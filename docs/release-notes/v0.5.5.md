## FilePumper 0.5.5

Массовое создание файлов сразу нескольких типов: отметил форматы, задал
количество — и получил смешанную серию. Распределение на выбор: поровну на
каждый тип или случайно из отмеченных.

### Что нового

- **Несколько типов в одном запуске.** На вкладке «Создать файл» теперь
  чекбоксы `.bin`, `.png`, `.gif`, `.jpg`, `.webp` (и кнопки «Все типы» /
  «Только .bin»): размер и разброс задаются один раз, а файлы создаются всех
  отмеченных типов сразу. В CLI то же делает список в `--type`:
  `generate --size 10 --type png,gif,bin` (или `--type all`).
- **Распределение на выбор.** «Поровну на каждый тип» (`--mix even`, по
  умолчанию) создаёт по `--count` файлов каждого отмеченного типа:
  `generate --size 10 --type png,gif --count 2` даёт две PNG и два GIF.
  «Случайно из выбранных» (`--mix random`) создаёт всего `--count` файлов, а
  тип каждого выбирается случайно из отмеченных.
- **Понятный итог в окне.** Под настройками видно, сколько файлов получится
  («всего файлов: N») и как будут выглядеть имена для каждого типа — с учётом
  режима «Имена» (`file_10MB.png`, `file.png`, `green-apple-4821.gif`).
- **`--type all`** создаёт все пять типов, а повторяющиеся типы в списке
  отбрасываются: `--type png,png,gif` = `png,gif`.

### Что изменилось в поведении

- `--count` считается по распределению: при `--mix even` это файлов на каждый
  тип, при `--mix random` — всего файлов. С одним типом поведение прежнее.
- `--dry-run` печатает выбранные типы и распределение:
  `План: 4 файл(ов), типы: png, gif, имена «с размером», распределение: «поровну на каждый тип»`.

### Что не менялось

Формат контейнера (версия 2), шифрование (Argon2id + ChaCha20-Poly1305),
размеры файлов и режимы накачки. `generate` без новых флагов работает как
раньше: один тип (`.bin` по умолчанию), `--count N` файлов на каждый размер.
Файлы, созданные 0.5.4 и раньше, читаются этой версией без изменений.

### Требования

- **Windows:** DirectX 12 или Vulkan для окна; если система ругается на отсутствующие DLL — Microsoft Visual C++ 2015-2022 x64.
- **Linux:** glibc ≥ 2.17; для окна нужны X11 или Wayland и драйвер Vulkan/Mesa; CLI-версии кроме `libc` ничего не требуется.

### Быстрый старт

```powershell
# три PNG и три GIF по 10 МБ в одной папке
FilePumper-cli.exe generate --size 10 --type png,gif --count 3 --out-dir .\made

# шесть файлов случайных типов из отмеченных
FilePumper-cli.exe generate --size 10 --type bin,png,gif --count 6 --mix random --out-dir .\made
```

```bash
tar -xzf FilePumper-0.5.5-linux-x64.tar.gz
chmod +x linux/file-pumper linux/file-pumper-cli
./linux/file-pumper-cli generate --size 1 --type png,gif --count 2 --out-dir ./made
```

Полное описание режимов, формата контейнера и всех команд — в [README.md](https://github.com/Xvicd/FilePumper/blob/main/README.md).
