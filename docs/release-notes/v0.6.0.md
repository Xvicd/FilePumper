## FilePumper 0.6.0

Случайные имена стали разнообразнее — длина имени может быть случайной, а слова
в именах разной длины. У создаваемых картинок теперь задаётся видимый размер:
`--image-size 512x512` вместо служебной заглушки 16×16.

### Что нового

- **Случайная длина имени.** `--random-length` принимает фиксированное число
  (`10`), диапазон (`5-12`) или `random` (4…16). При диапазоне у каждого имени
  своя длина — серия не выглядит «под копирку». В окне на вкладке «Создать файл»
  рядом с полем «Длина» появилась галочка «случайная»: включается — появляются
  поля «от» и «до».
- **Слова разной длины.** В словарях случайных имён есть и короткие (`ivy`,
  `oak`, `apt`, `wee`), и длинные (`cobblestone`, `constellation`,
  `breathtaking`) слова, поэтому имена из слов тоже получаются разной длины:
  `happy-pebble-8418`, `rapid-ivy-5876`, `sunny-cobblestone-5337`.
- **Размер видимой картинки.** `--image-size 512x512` (`1024x768`, или одно
  число — квадрат) задаёт «шумовую» картинку, которая занимает всю площадь
  файла: PNG, GIF, JPEG и WebP выглядят как настоящее шумовое фото нужного
  разрешения. Объём при этом остаётся ровно целевым — остальное лежит внутри
  структуры файла. В окне это поля «Картинка: Ш × В px» с кнопками `512×512` и
  `16×16`; по умолчанию картинка служебная, 16×16.

### Примеры

```powershell
# случайная длина имени: у каждого файла своя, от 5 до 12 символов
FilePumper-cli.exe generate --size 1 --count 20 --names random --random-style chars --random-length 5-12 --out-dir .\made

# совсем случайная длина (4…16) с готовым набором символов
FilePumper-cli.exe generate --size 1 --count 20 --names random --random-style chars --random-length random --random-alphabet 0123456789abcdef --out-dir .\made

# шумовая картинка 512×512 при размере файла ровно 25 МБ
FilePumper-cli.exe generate --size 25 --type png --image-size 512x512 --name noise --out-dir .\made
```

### Что не менялось

Формат контейнера (версия 2), шифрование (Argon2id + ChaCha20-Poly1305) и
команды: файлы и сохранённые профили от 0.5.9 и раньше читаются этой версией без
изменений. Новые настройки по умолчанию прежние: случайная длина выключена,
картинка 16×16.

### Требования

- **Windows:** DirectX 12 или Vulkan для окна; если система ругается на
  отсутствующие DLL — Microsoft Visual C++ 2015-2022 x64.
- **Linux:** glibc ≥ 2.17; для окна нужны X11 или Wayland и драйвер Vulkan/Mesa;
  CLI-версии кроме `libc` ничего не требуется.

### Как собрано и проверено

- `cargo fmt --all --check`, `cargo clippy --all-targets -- -D warnings` и
  `cargo test` — 216 тестов.
- Добавлены проверки: разбор длины (`8`, `5-12`, `random`, ошибки), попадание
  случайной длины во все значения диапазона на 300 именах, короткие и длинные
  слова в словарях, `--random-length 5-12` в CLI, `--image-size 512x512` с
  проверкой разрешения картинки и точного размера файла.
- Проверено вручную: `--random-length 5-12` даёт имена 5–12 символов,
  `--image-size 512x512` — PNG 512×512 ровно на 2 МБ, JPEG 1024×768 на 3 МБ,
  GIF 256×256 на 1,5 МБ; все открываются Pillow.
- Сборка релиза — workflow `Release` по тегу `v0.6.0`: Windows
  (`cargo build --release --bins`) и Linux (`cargo zigbuild`, glibc 2.17);
  те же проверки повторяет workflow `CI` на Windows и Linux.

### Быстрый старт

```powershell
# окно: «Создать файл» → тип png → «Картинка» 512×512 → «Создать файл»
FilePumper.exe

# CLI: серия шумовых фото ровно по 5 МБ
FilePumper-cli.exe generate --size 5 --type png --count 10 --image-size 1024x768 --out-dir .\series
```

```bash
tar -xzf FilePumper-0.6.0-linux-x64.tar.gz
chmod +x linux/file-pumper linux/file-pumper-cli
./linux/file-pumper-cli generate --size 5 --type png --image-size 512x512 --out-dir ./made
```

Полное описание режимов, формата контейнера и всех команд — в [README.md](https://github.com/Xvicd/FilePumper/blob/main/README.md).
