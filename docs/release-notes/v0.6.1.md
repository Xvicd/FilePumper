## FilePumper 0.6.1

Генерация научилась создавать документы и картинки «на заказ»: PDF, DOCX и XLSX
ровно нужного размера, пять видов шума вместо одного и пресеты разрешений.
`--size` понимает единицы измерения.

### Что нового

- **PDF, DOCX и XLSX с нуля.** `--type pdf`, `docx`, `xlsx` создают настоящий
  документ ровно заданного размера: одна страница PDF (или документ Word /
  лист Excel) плюс заполнитель из криптослучайных байтов. Файл открывается
  своей программой, но не сжимается архивом. `--type all` теперь включает и
  эти три типа.
- **Пять видов шума.** `--noise rgb|gradient|checker|tv|perlin`: цветной снег
  (как раньше), плавный градиент, шахматка, телевизионный снег и плавные пятна
  в духе шума Перлина. В окне — список «Шум» рядом с размером картинки.
- **Пресеты разрешений в окне.** 1920×1080, 1080×1080, 2560×1440, A4 в 300 dpi
  (2480×3508), 512×512 и 16×16 — одним нажатием.
- **Единицы размера.** `--size` принимает `700KB`, `1.5GB`, `512B`; без суффикса
  по-прежнему мегабайты. Работает и для списка (`--size 5,10`).

### Примеры

```powershell
# настоящий PDF, DOCX и XLSX ровно на 2 МБ
FilePumper-cli.exe generate --size 2 --type pdf,docx,xlsx --out-dir .\made

# шахматная картинка 1920×1080, файл ровно 10 МБ
FilePumper-cli.exe generate --size 10 --type png --image-size 1920x1080 --noise checker --out-dir .\made

# 700 КБ вместо мегабайтов
FilePumper-cli.exe generate --size 700KB --type bin --out-dir .\made
```

В окне: вкладка «Создать файл» → тип `png` → строка «Шум» и пресеты разрешений
(1920×1080, 1080×1080, 2560×1440, A4 300 dpi, 512×512, 16×16). PDF/DOCX/XLSX —
это отдельные галочки в «Типы файлов».

### Ограничения

- Внутрь PDF/DOCX/XLSX полезную нагрузку пока встроить нельзя: генерация
  скажет об этом понятной ошибкой. Нагрузка по-прежнему доступна для картинок
  и обычных файлов (`--type bin|png|gif|jpg|webp`).
- Если цель меньше самой картинки (например, 512×512 цветного снега в 0.5 МБ),
  генерация честно скажет минимальный размер. Для маленьких целей подойдут
  градиент, шахматка или пятна — они сжимаются.

### Что не менялось

Формат контейнера (версия 2), команды `pump`/`embed`/`extract`/`inspect`/
`verify`/`clean` и сохранённые профили: файлы и настройки от 0.6.0 и раньше
читаются этой версией без изменений.

### Требования

- **Windows:** DirectX 12 или Vulkan для окна; если система ругается на
  отсутствующие DLL — Microsoft Visual C++ 2015-2022 x64.
- **Linux:** glibc ≥ 2.17; для окна нужны X11 или Wayland и драйвер Vulkan/Mesa;
  CLI-версии кроме `libc` ничего не требуется.

### Как собрано и проверено

- `cargo fmt --all --check`, `cargo clippy --all-targets -- -D warnings` и
  `cargo test` — 223 теста.
- Добавлены проверки: генерация документов точного размера и их читаемость,
  пять видов шума и их различимость, шахматка ровно из двух цветов, разбор
  единиц размера и ошибки для неизвестных суффиксов.
- Проверено на реальных программах: сгенерированный PDF открывается и
  рендерится (LibreOffice), DOCX читается python-docx (`FilePumper`), XLSX —
  openpyxl (лист `Sheet1`, `A1 = FilePumper`), размеры ровно 1 048 576 байт.
- Сборка релиза — workflow `Release` по тегу `v0.6.1`: Windows
  (`cargo build --release --bins`) и Linux (`cargo zigbuild`, glibc 2.17);
  те же проверки повторяет workflow `CI` на Windows и Linux.

### Быстрый старт

```powershell
# окно: «Создать файл» → png → пресет 1920×1080 → шум «шахматка»
FilePumper.exe

# CLI: документы ровно по 5 МБ
FilePumper-cli.exe generate --size 5 --type pdf,docx,xlsx --out-dir .\docs
```

```bash
tar -xzf FilePumper-0.6.1-linux-x64.tar.gz
chmod +x linux/file-pumper linux/file-pumper-cli
./linux/file-pumper-cli generate --size 2 --type pdf --out-dir ./made
```

Полное описание режимов, формата контейнера и всех команд — в [README.md](https://github.com/Xvicd/FilePumper/blob/main/README.md).
