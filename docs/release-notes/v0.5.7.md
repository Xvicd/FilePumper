## FilePumper 0.5.7

Удобство для скриптов и окна: машинный JSON, тихий режим, скорость и ETA,
сопоставление пар по именам, профили, индикатор пароля и отдельные зоны
drag & drop.

### Что нового

- **CLI для скриптов.** `--quiet`, `--no-progress`, `--json`,
  `--password-file`, `--password-stdin` и `--jobs 0` (автоматически по числу
  ядер). JSON поддерживают `pump`, `generate`, `embed`, `extract`, `inspect`,
  `verify` и `--dry-run`.
- **Прогресс.** В терминале видны скорость и ETA, в окне — прогресс каждого
  файла, общая скорость и остаток времени. Перед запуском проверяется свободное
  место на диске.
- **Пары по именам.** `--pair-by name` и кнопка «Сопоставить по именам»:
  `photo.png` получает `photo.zip` и `photo.mp3` (несколько файлов — бандл),
  `report.pdf` — `report.*`. Регистр не важен; если пары не нашлись, программа
  перечислит их в ошибке.
- **Профили и пресеты.** Настройки можно сохранить под именем, загрузить или
  удалить. Рядом с размером — быстрые кнопки 2/5/10/20/50/100 МБ.
- **Пароли в окне.** Переключатель «Показать пароли» и индикатор надёжности
  пароля: слабый, средний или сильный.
- **Разные зоны drag & drop** на вкладке «Спрятать / извлечь»: файлы,
  брошенные на блок носителей, не попадают в нагрузку, и наоборот. Вне зон
  показывается подсказка.

### Примеры

```powershell
# JSON для скрипта, без прогресса и служебного текста
FilePumper-cli.exe pump .\photo.jpg --size 10 --json --quiet

# пароль из файла, без попадания в историю shell
FilePumper-cli.exe extract .\photo_with_payload.png --password-file .\password.txt --json

# пары по именам: photo.png <- photo.zip, report.pdf <- report.mp3
FilePumper-cli.exe embed .\photo.png .\report.pdf --payload .\photo.zip --payload .\report.mp3 --pair-by name --out-dir .\out
```

### Что не менялось

Формат контейнера (версия 2), шифрование (Argon2id + ChaCha20-Poly1305),
команды и файлы, созданные 0.5.6 и раньше, читаются этой версией без изменений.

### Требования

- **Windows:** DirectX 12 или Vulkan для окна; если система ругается на отсутствующие DLL — Microsoft Visual C++ 2015-2022 x64.
- **Linux:** glibc ≥ 2.17; для окна нужны X11 или Wayland и драйвер Vulkan/Mesa; CLI-версии кроме `libc` ничего не требуется.

### Как собрано и проверено

- `cargo fmt --all --check`, `cargo clippy --all-targets -- -D warnings` и
  `cargo test` — 177 тестов.
- Новое покрыто тестами: разбор флагов CLI, `--jobs 0`, `--pair-by`,
  сопоставление пар по именам, оценка надёжности пароля, форматирование
  скорости/ETA и генерация shell-дополнений.
- Сборка релиза — workflow `Release` по тегу `v0.5.7`: Windows
  (`cargo build --release --bins`) и Linux (`cargo zigbuild`, glibc 2.17);
  те же проверки повторяет workflow `CI` на Windows и Linux.

### Быстрый старт

```powershell
# профиль в окне: сохраните «PNG 10 МБ» и загружайте одним нажатием
FilePumper.exe

# пары по именам из CLI
FilePumper-cli.exe embed .\photo.png .\report.pdf --payload .\photo.zip --payload .\report.mp3 --pair-by name --out-dir .\out
```

```bash
tar -xzf FilePumper-0.5.7-linux-x64.tar.gz
chmod +x linux/file-pumper linux/file-pumper-cli
./linux/file-pumper-cli --help
```
