## FilePumper 0.5.6

Исправление добивки GIF: на некоторых значениях зазора программа могла
зависнуть вместо создания файла нужного размера.

### Что исправлено

- **Зависание при GIF-паддинге.** Если разница между целевым и текущим
  размером давала остаток `4` по модулю 256 (4, 260, 516, …), поиск длины
  данных для Comment Extension бесконечно прыгал между двумя значениями.
  Теперь план добивки считается напрямую, а на границах подблоков используется
  пустой комментарий и второй с данными — файл получается ровно нужной длины.
- **Непредставимые зазоры.** Зазоры 1, 2 и 4 байта нельзя выразить
  комментариями GIF. Вместо зависания возвращается понятная ошибка, а исходный
  файл остаётся нетронутым.
- **Проверка результата.** После записи сверяется фактический размер файла:
  результат с неверной длиной не заменит исходный файл.

### Тесты

- Точный размер на границах подблоков: 253–260, 516, 772, 1000 и 4096 байт.
  Для каждого результата дополнительно проверяется, что GIF открывается
  декодером.
- Зазоры 1, 2 и 4 байта завершаются ошибкой без изменения файла.

### Что не менялось

Формат контейнера (версия 2), шифрование (Argon2id + ChaCha20-Poly1305),
команды CLI и файлы, созданные 0.5.5 и раньше, читаются этой версией без
изменений. Поведение `generate` и `pump` для обычных размеров прежнее.

### Требования

- **Windows:** DirectX 12 или Vulkan для окна; если система ругается на отсутствующие DLL — Microsoft Visual C++ 2015-2022 x64.
- **Linux:** glibc ≥ 2.17; для окна нужны X11 или Wayland и драйвер Vulkan/Mesa; CLI-версии кроме `libc` ничего не требуется.

### Быстрый старт

```powershell
# файл ровно на 10 МБ с валидной GIF-анимацией
FilePumper-cli.exe generate --size 10 --type gif --out-dir .\made

# добить GIF до точного размера, включая границы подблоков
FilePumper-cli.exe pump .\photo.gif --size 1 --method animation --format gif --out-dir .\big
```

```bash
tar -xzf FilePumper-0.5.6-linux-x64.tar.gz
chmod +x linux/file-pumper linux/file-pumper-cli
./linux/file-pumper-cli generate --size 1 --type gif --out-dir ./made
```

Полное описание режимов, формата контейнера и всех команд — в [README.md](https://github.com/Xvicd/FilePumper/blob/main/README.md).
