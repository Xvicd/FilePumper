## FilePumper 0.5.3

Случайные имена на выбор: слова `green-apple-4821` или набор символов `k7fq2mzp`.

### Что нового

- У режима «случайное» появился **вид имени**: «слова» (`green-apple-4821`:
  прилагательное, существительное и число) или «набор символов» (`k7fq2mzp`).
- Для набора символов задаются **длина** (3…48, по умолчанию 10) и **алфавит** —
  из каких символов собирать имя. В окне рядом с полем есть готовые наборы
  `a-z`, `a-z0-9`, `0-9`, `hex`, `A-Za-z0-9`; в CLI те же настройки задают флаги
  `--random-style words|chars`, `--random-length N`, `--random-alphabet НАБОР`.
- Символы, недопустимые в имени файла, отбрасываются (остаются латиница, цифры,
  «-» и «_»): окно предупреждает об этом, а CLI пустой алфавит считает ошибкой.
- Кнопка **«другой пример»** рядом с примером имени показывает ещё один вариант.

### Что исправлено

- Пример имени в окне больше не «перебирает» варианты на каждом кадре: случайная
  основа для примера берётся по зерну, поэтому пока настройки не меняли, пример
  стоит на месте.
- `--names` и `--random-style` понимают слова в любом регистре, включая кириллицу:
  `--names Случайное`, `--random-style СИМВОЛЫ`.

### Что не менялось

Поведение команд, формат контейнера (версия 2), содержимое файлов и размеры — всё
как в 0.5.2. `--names random` без новых флагов даёт прежние имена вида
`quiet-river-4821.png`.

### Обновление с 0.5.2

Совместимо в обе стороны: файлы, созданные 0.5.2 (и более ранними версиями),
читаются этой версией. Сохранённые настройки окна переносятся без потерь — новые
поля (вид имени, длина, алфавит) берут значения по умолчанию.

### Требования

- **Windows:** DirectX 12 или Vulkan для окна; если система ругается на отсутствующие DLL — Microsoft Visual C++ 2015-2022 x64.
- **Linux:** glibc ≥ 2.17; для окна нужны X11 или Wayland и драйвер Vulkan/Mesa; CLI-версии кроме `libc` ничего не требуется.

### Как собрано и проверено

- `cargo test --all-targets` — 137 тестов (76 unit, 6 пакетный CLI, 13 возможностей
  CLI, 11 генерации, 8 разброса, 10 режимов имён, 8 устойчивость, 5 сквозных),
  `cargo clippy --all-targets -- -D warnings` и `cargo fmt --check` без замечаний.
- Windows (собрано локально, `cargo build --release --bins`): `--version` →
  `FilePumper 0.5.3`; `pump --names random --random-style chars --random-length 8
  --random-alphabet abcdef0123456789` даёт имена вида `a41f0c7d.png`; окно
  показывает пример имени, который не меняется сам по себе, а кнопка «другой
  пример» выдаёт новый вариант.
- Linux (сборка CI, `zigbuild` glibc 2.17; проверено в WSL Kali): `file-pumper-cli
  --version` → `FilePumper 0.5.3`, `generate --size 3 --count 3 --names random
  --random-style chars --random-length 8 --type png --verify` даёт три валидных
  PNG со случайными именами из заданного алфавита, `ldd` — только
  `libc`/`libm`/`libpthread`/`libdl`.

### Быстрый старт (Linux)

```bash
tar -xzf FilePumper-0.5.3-linux-x64.tar.gz
chmod +x linux/file-pumper linux/file-pumper-cli
./linux/file-pumper-cli pump --from-dir ./photos --size 5 --names random --random-style chars --random-length 8
```

Полное описание режимов, формата контейнера и всех команд — в [README.md](https://github.com/Xvicd/FilePumper/blob/main/README.md).
