## FilePumper 0.5.2

Точная подсказка о разбросе в окне.

### Что исправлено

- В окне подсказка «в какой диапазон попадёт размер» считалась только от
  указанного размера. При режимах «не меньше» и «прибавить» база зависит от
  исходного файла, поэтому числа были неверными: например, при «прибавить 10 МБ»
  и разбросе 2 МБ показывалось «от 8,00 до 12,00 МБ», хотя файл получался
  «исходный размер + 8…12 МБ».
- Теперь диапазон в мегабайтах виден там, где он точен, — в режиме «точно»
  («Каждый файл получит случайный размер от 395,00 до 405,00 МБ»), а в остальных
  режимах вместо чисел печатается правило: «Разброс ±5MB применится к размеру,
  который получится после режима «прибавить»».
- Предупреждение «разброс не меньше самого размера» тоже показывается только в
  режиме «точно»: в других режимах база больше введённого размера, и это была
  ложная тревога.

### Что не менялось

Поведение команд, формат контейнера (версия 2), содержимое файлов и размеры —
всё как в 0.5.1. Обновляться стоит ради понятного окна: результаты работы
0.5.1 и 0.5.2 неотличимы.

### Обновление с 0.5.1

Совместимо в обе стороны: файлы, созданные 0.5.1 (и 0.5.0), читаются этой
версией, а файлы 0.5.2 без новых возможностей читаются 0.5.1. Сохранённые
настройки окна переносятся без потерь.

### Требования

- **Windows:** DirectX 12 или Vulkan для окна; если система ругается на отсутствующие DLL — Microsoft Visual C++ 2015-2022 x64.
- **Linux:** glibc ≥ 2.17; для окна нужны X11 или Wayland и драйвер Vulkan/Mesa; CLI-версии кроме `libc` ничего не требуется.

### Как собрано и проверено

- `cargo test --all-targets` — 126 тестов (69 unit, 6 пакетный CLI, 13 возможностей
  CLI, 11 генерации, 8 разброса, 6 режимов имён, 8 устойчивость, 5 сквозных),
  `cargo clippy --all-targets -- -D warnings` и `cargo fmt --check` без замечаний.
- Windows (собрано локально, `cargo build --release --bins`): `--version` →
  `FilePumper 0.5.2`; `generate --size 3 --vary 0.5 --count 3 --type png --verify`
  даёт три валидных PNG случайных размеров, имена совпадают с фактическими
  размерами; `pump --size 1 --vary 0.25 --vary-mode minus` даёт файл меньше
  мегабайта; `--dry-run` печатает размер и разброс, ничего не создавая; окно
  открывается с заголовком FilePumper, подсказка о разбросе показывает диапазон
  для режима «точно» и правило — для «не меньше»/«прибавить».
- Linux (сборка CI, `zigbuild` glibc 2.17; проверено в WSL Kali): `file-pumper-cli
  --version` → `FilePumper 0.5.2`, `generate --size 3 --vary 0.5 --count 3 --type
  png --verify` даёт три файла со случайными размерами, `ldd` — только
  `libc`/`libm`/`libpthread`/`libdl`, то есть CLI-версии не нужен ни X11, ни Vulkan.

### Быстрый старт (Linux)

```bash
tar -xzf FilePumper-0.5.2-linux-x64.tar.gz
chmod +x linux/file-pumper linux/file-pumper-cli
./linux/file-pumper-cli generate --size 400 --vary 5 --type png --out-dir ./big
```

Полное описание режимов, формата контейнера и всех команд — в [README.md](https://github.com/Xvicd/FilePumper/blob/main/README.md).
