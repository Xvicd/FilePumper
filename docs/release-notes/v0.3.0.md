## FilePumper 0.3.0

Пакетная накачка: несколько файлов за один запуск — окно приложения и командная строка, Rust.

### Что нового

- **Пакетный `pump`** — `file-pumper-cli pump <вход>... --size <МБ> [--out-dir ПАПКА]`:
  файлы обрабатываются по очереди, ошибка одного не прерывает остальные, в конце
  сводка по каждому файлу и код выхода `1`, если хоть один файл не удался.
- **`extract` и `inspect` принимают несколько носителей**; `extract --out-dir`
  складывает извлечённые файлы в одну папку.
- **Имена результатов** — `<имя>_<размер>MB.<расширение>` (например, `photo_10MB.png`);
  существующие файлы не перезаписываются, при совпадении добавляется суффикс
  `-2`, `-3`.
- **В окне** — мультивыбор файлов, drag & drop всех перетащенных файлов, список
  пакета с состоянием каждой строки (ожидает / обработка / готово с размером /
  ошибка), удаление строк, «Очистить», выбор папки результатов, общий прогресс
  «Файл 3 из 8» и сводный диалог после пакета.
- Старый синтаксис `pump <вход> <выход>` продолжает работать, но печатает
  предупреждение: для точного имени результата используйте `--output`.

### Требования

- **Windows:** DirectX 12 или Vulkan для окна; если система ругается на отсутствующие DLL — Microsoft Visual C++ 2015-2022 x64.
- **Linux:** glibc ≥ 2.17; для окна нужны X11 или Wayland и драйвер Vulkan/Mesa; CLI-версии кроме `libc` ничего не требуется.

### Как собрано и проверено

- Бинарники собраны в GitHub Actions: Windows — на `windows-latest`, Linux — через `cargo zigbuild` под glibc 2.17.
- Перед сборкой: `cargo test --all-targets` — 46 тестов пройдены (27 unit, 8 устойчивость,
  5 сквозных, 6 пакетный CLI), `cargo clippy --all-targets -- -D warnings` и
  `cargo fmt --check` без замечаний.
- Локальная проверка пакетного режима (Windows, `file-pumper-cli`):
  `pump one.png two.png note.txt --size 1 --method png-chunks --out-dir out` —
  два PNG созданы, неподдерживаемый `.txt` попал в список ошибок, код выхода `1`;
  `pump note.txt out.bin --size 1` (старый синтаксис) — ровно 1 048 576 байт;
  `inspect` и `extract` по двум носителям — извлечено `secret.zip` и `secret-2.zip`.

### Быстрый старт (Linux)

```bash
tar -xzf FilePumper-0.3.0-linux-x64.tar.gz
chmod +x linux/file-pumper linux/file-pumper-cli
./linux/file-pumper-cli --help
```

Полное описание режимов, формата контейнера и всех команд — в [README.md](https://github.com/Xvicd/FilePumper/blob/main/README.md).
