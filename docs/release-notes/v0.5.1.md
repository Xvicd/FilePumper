## FilePumper 0.5.1

Разброс размера «плюс-минус» и переработанное окно.

### Что нового

- **Разброс размера** — `--vary <МБ>` вместо статичного размера: `--size 400
  --vary 5` даёт файл на 395…405 МБ, и у каждого файла пакета отклонение своё.
  Направление выбирается флагом `--vary-mode plus|minus|both`: только прибавлять,
  только убавлять или в обе стороны (по умолчанию). Работает и в `pump`, и в
  `generate`; `--vary 0` выключает разброс.
- **Точность не страдает** — разброс применяется к размеру, который получился
  после `--size-mode`, и файл записывается ровно того размера, который выпал:
  `--verify` проходит, а имя (`photo_3.87MB.png`) показывает фактический размер.
  Ниже одного байта размер не опускается; если разброс не меньше самого размера,
  программа предупреждает.
- **Окно переработано для понятности** — три вкладки по задачам («Накачать
  файлы», «Спрятать / извлечь», «Создать файл»), настройки собраны в подписанные
  группы, на каждой вкладке одна крупная кнопка запуска, а статус и прогресс с
  кнопкой «Отмена» закреплены внизу окна и видны всегда. В поле «Разброс» рядом
  с размером сразу видно, в какой диапазон попадёт файл.
- **Ничего не потеряно** — методы накачки, режимы размера, имена результатов
  (теперь тремя радиокнопками), папка результатов, носители и нагрузка, сжатие,
  копии, пароль, «второе дно», прогресс, отмена, окно результата с «Показать в
  проводнике», предпросмотр извлечения, drag & drop и сохранение настроек на
  месте. Добавились кнопка «Добавить папку…» (папка вместе с подпапками) и
  запоминание разброса, режима имён и открытой вкладки.

### Обновление с 0.5.0

Формат контейнера не менялся (версия 2): файлы, созданные 0.5.0, читаются этой
версией. Новые флаги старым версиям неизвестны — они сообщат об ошибке в
аргументах, но созданные файлы читают нормально. Старые настройки окна читаются:
недостающие поля берутся по умолчанию.

### Требования

- **Windows:** DirectX 12 или Vulkan для окна; если система ругается на отсутствующие DLL — Microsoft Visual C++ 2015-2022 x64.
- **Linux:** glibc ≥ 2.17; для окна нужны X11 или Wayland и драйвер Vulkan/Mesa; CLI-версии кроме `libc` ничего не требуется.

### Как собрано и проверено

- `cargo test --all-targets` — 126 тестов (69 unit, 6 пакетный CLI, 13 возможностей
  CLI, 11 генерации, 8 разброса, 6 режимов имён, 8 устойчивость, 5 сквозных),
  `cargo clippy --all-targets -- -D warnings` и `cargo fmt --check` без замечаний.
- Windows (собрано локально, `cargo build --release --bins`):
  `generate --size 3 --vary 0.5 --count 3 --type png --verify` даёт три валидных
  PNG случайных размеров (`2.83`, `3.34`, `3.42` МБ), имена совпадают с
  фактическими размерами; `pump --size 1 --vary 0.25 --vary-mode minus` даёт файл
  на 0.95 МБ; `--dry-run` печатает размер и разброс, ничего не создавая;
  `pump --vary -1` и `--vary-mode sideways` отклоняются с кодом 1.
- Окно проверено запуском: `FilePumper.exe` открывается с заголовком FilePumper,
  вкладки переключаются, консоль не появляется (PE subsystem 2), у
  `FilePumper-cli.exe` — subsystem 3.
- Linux (сборка CI, `zigbuild` glibc 2.17; проверено в WSL Kali): `file-pumper-cli
  --version` → `FilePumper 0.5.1`, `generate --size 3 --vary 0.5 --count 3 --type
  png` даёт три файла со случайными размерами, `ldd` — только
  `libc`/`libm`/`libpthread`/`libdl`, то есть CLI-версии не нужен ни X11, ни Vulkan.

### Быстрый старт (Linux)

```bash
tar -xzf FilePumper-0.5.1-linux-x64.tar.gz
chmod +x linux/file-pumper linux/file-pumper-cli
./linux/file-pumper-cli generate --size 400 --vary 5 --type png --out-dir ./big
```

Полное описание режимов, формата контейнера и всех команд — в [README.md](https://github.com/Xvicd/FilePumper/blob/main/README.md).
